# Miners Villa

Уурхайчин-3 төслийн хаус хотхоны сайт: загварын scroll hero, интерактив генплан, 3D хотхон (Three.js), байшин сонгоход задрах дотор тал, дотогш алхдаг 3D, давхрын байгууламж.

Статик сайт. `index.html`-ийг шууд нээнэ эсвэл GitHub Pages дээр байршуулна (Settings → Pages → main / root).

- `index.html`: сайт (Three.js r128-г cdnjs-ээс ачаална)
- `plans.json`: төлөвлөгөөнөөс гаргасан ханын геометр
- `img/`: рендер, төлөвлөгөө, генплан
